# beauty-app

化粧品メーカー・広告担当者向けの小さな商品説明レビュー画面です。`@tazimagumi/client` 経由で親リポジトリの `beauty-kit` サーバーを呼び出し、文章の表現チェック、全成分の照合、任意の根拠資料への相談を1画面で行います。

## 起動

Node.js 22.18 以上が必要です。親リポジトリのルートで依存を入れてから、2つのターミナルで起動します。

```sh
# 親リポジトリのルート
npm ci
npm run --workspace=beauty-kit serve

# apps/beauty-app
npm start
```

ブラウザで <http://127.0.0.1:5173> を開きます。キットサーバーのURLは `BEAUTY_KIT_URL`、画面の待受ポートは `APP_PORT` で変更できます。

根拠資料への相談を使う場合は、親リポジトリの rag CLI で用意した知識DBを `KIT_RAG_DB` に指定してからキットサーバーを起動してください。DBが無いときは表現チェックと成分照合を使え、相談だけ利用できない旨を画面に表示します。

## 画面の流れ

1. 商品説明または広告文と全成分表示を入力します。
2. 表現チェック結果（該当箇所・強さ・言い換え例・出典）と成分照合結果を確認します。
3. 必要に応じて質問を入力すると、利用可能な承認済み資料からの抜粋と引用を表示します。

APIキーはブラウザに置きません。入力内容をアプリで保存・記録する機能はありません。通常の処理はローカルの beauty-kit に送ります。

## 判定の限界

表現ルールと成分データは暫定です。指摘が無いことは広告表現の適法性・妥当性を示しません。成分表から濃度や製品の効果・安全性は分かりません。相談の回答も資料抜粋であり、完全な根拠や個別製品への適用を保証しません。必ず担当者が原典と文脈を確認してください。

## 開発時の型チェック

依存関係を親リポジトリのルートで `npm ci` した後、このディレクトリで実行します。

```sh
npm run typecheck
```
